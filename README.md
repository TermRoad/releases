# TermRoad releases

Downloads of [TermRoad](https://termroad.com) for macOS, and `appcast.xml`, the feed the app
checks for updates (served by GitHub Pages).

**Download:** [the latest release](https://github.com/TermRoad/releases/releases/latest).

Everything here is published by TermRoad's release workflow: each zip is signed with Developer
ID, notarised by Apple, and signed for the app's updater. Please don't open issues or pull
requests here; for support, see [termroad.com](https://termroad.com).
